# Abdelaziz Abuthuraya — CV & Portfolio

Arabic-first, bilingual professional portfolio connecting industrial engineering, production planning, process improvement, and digital systems development.

## Highlights

- Arabic and English content with complete RTL/LTR switching
- Responsive, accessible, and print-friendly interface
- Selected experience and academic results drawn from the supplied resumes
- Three focused technical case studies: FORM, Kayan, and ECLIPSE
- Downloadable Arabic and English CV PDFs
- No analytics, forms, cookies, or personal-data collection

## Development

```bash
npm install
npm run dev
```

Release checks:

```bash
npm run check
npm audit --audit-level=high
```

## Privacy

The public portfolio intentionally omits national ID, date of birth, nationality, and work-permit details. Contact is limited to professional channels already supplied by the owner.
